-->PROBLEM STATEMENT:
Managing banking operations manually can be time-consuming and prone to errors. This project develops a Console-Based Banking Management System using Python to automate essential banking operations such as account creation, deposits, withdrawals, balance inquiries, and account closure, ensuring efficient and accurate account management.

-->OBJECTIVE:
--Develop a menu-driven banking application using Python.
--Manage customer accounts efficiently.
--Perform secure banking transactions with proper validation.
--Improve accuracy and reduce manual errors.

-->FEATURES:
1.Create a new account.
2.Deposit money.
3.Withdraw money.
4.Check account balance.
5.Display all customer accounts.
6.Close an account.
7.Input validation and error handling.

-->DATA STRUCTURES AND PYTHON CONCEPTS:
--Dictionary: Stores customer account details using Account ID as the key.
--Functions: Organizes each banking operation into reusable modules.
--Loops: Displays the menu continuously until the user exits.
--Conditional Statements: Validates user input and transaction rules.
--Exception Handling (optional): Handles invalid inputs gracefully.
